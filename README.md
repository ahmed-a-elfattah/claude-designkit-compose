# Claude DesignKit for Compose

**Turn a Claude Design export into a ready-to-use Jetpack Compose design system — theme, icons, components and EN/AR strings — in one click from Android Studio.**

## Why

Every new Android project starts the same way: someone hands you a design, and you spend hours hand-writing `Color.kt`, `Type.kt`, a light/dark theme, icon files and button variants — then redo it every time the design changes.

DesignKit reads the export and writes that code for you. Re-import whenever the design changes; your hand-written code is never touched.

## Install

**Android Studio › Settings › Plugins › Marketplace** → search **"Claude DesignKit for Compose"** → Install.

Or install it from the [JetBrains Marketplace page](https://plugins.jetbrains.com/plugin/36162-claude-designkit-for-compose).

## Use it

1. Export your design system from Claude Design (zip or folder).
2. **Tools › Import Claude Design System…** and pick the export.
3. In the preview, choose the module, package, prefix and icon format. Untick any Material icon match or string you don't want.
4. Click **Import**. Later, run **Re-import Claude Design System** after the design changes.

## What it generates

| Output | Details |
|---|---|
| **Theme** | `Color.kt`, `Type.kt`, `Shape.kt`, `Spacing.kt`, `Elevation.kt`, `Theme.kt` with `AppTheme { }` and `AppTheme.colors / typography / shapes / spacing / elevation / sizes`, mapped onto `MaterialTheme`. Light and dark. Each token's design `usage` note becomes KDoc. |
| **Icons, no duplicates** | One `AppIcons` entry point. Icons Material already has (same name like `arrow-left` → `ArrowBack`, or same shape) are referenced, not copied. Only custom icons are generated, as `ImageVector` or `res/drawable` XML. Adds the Material icons dependency to your build or version catalog if needed. |
| **Components** | `AppButton`, `AppTextField`, `AppCard`, `AppChip`, `AppBadge`, with variants from the design's CSS (`.btn-*`, `.card`, `.input`, `.badge-*`) or `components.json`, each with `@Preview`s. |
| **English + Arabic strings** | Bilingual prototype text (`L('Back', 'رجوع')` or `{ en, ar }` objects) goes into `values/strings.xml` and `values-ar/strings.xml`. Joined values become format strings (`"Refund · %1$s"`). |

## Safe re-imports

- Generated files carry a `Generated by Claude DesignKit for Compose` header and are listed in `.claude-design-import`.
- Files generated by releases before 1.0.1 carry the old `Generated by Claude Design Importer` header. They are still recognized as generated, so a re-import updates them, even if `.claude-design-import` is missing.
- Re-imports only touch those files, and remove icons you deleted from the design.
- Hand-written files at the same path are never overwritten.
- Strings live inside a marked `Claude DesignKit: begin … end` block in `strings.xml`; your own entries outside it are never touched. An old `Claude Design Importer` block is replaced by the new one, not duplicated. Keys that clash with yours or with Java keywords get a `_text` suffix.

## Supported inputs

- Claude Design exports: `ds/<name>/tokens.json` (colors, type scale, spacing, radius, shadow, size tokens), CSS component classes, and Material Symbols names in the `.dc.html` artboard.
- Dark mode from `[data-theme=dark]`, `.dark`, `prefers-color-scheme: dark` or a `dark` token group.
- Also: W3C / Tokens Studio JSON tokens, CSS custom properties (including `oklch()` and shadcn-style `hsl` triplets), SVG icons and sprites, TTF/OTF fonts.

## Without the IDE

```bash
./gradlew :tools:generate \
  -Pexport=/path/export.zip \
  -Pmodule=/path/app \
  -Ppackage=com.example.app.designsystem \
  -Pnamespace=com.example.app \
  [-PiconFormat=DRAWABLE]
```

## Found an export it doesn't read correctly?

Claude Design's export format can change. If an import looks wrong, please [open an issue](https://github.com/ahmed-a-elfattah/claude-designkit-compose/issues) and attach the export (or a trimmed copy) — real exports become test fixtures.

## Develop

- Requires `JAVA_HOME` pointing at JDK 25 (Android Studio's: `/Applications/Android Studio.app/Contents/jbr/Contents/Home`). `androidStudioPath` in `gradle.properties` selects the IDE to build against.
- `./gradlew :core:test` — unit tests (fixture in `core/src/test/resources/fixture-export`).
- `./gradlew :plugin:runIde -PopenProject=/path/to/android/project` — sandbox Android Studio with the plugin.
- `./gradlew :plugin:buildPlugin` — builds `plugin/build/distributions/plugin-<version>.zip` (Settings › Plugins › ⚙ › Install Plugin from Disk…).
- `./gradlew :tools:buildMaterialIndex` — regenerates the Material icon geometry index.
- Readers live in `core/src/main/kotlin/dev/designimporter/core/reader/`.
